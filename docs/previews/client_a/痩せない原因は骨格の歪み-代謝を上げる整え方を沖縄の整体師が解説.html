骨格の歪みが代謝を下げる3つのメカニズム

骨格が歪むと内臓の位置がずれ、血流が悪化し、筋肉が正しく使えなくなるため基礎代謝が低下します。「ダイエットしても痩せない」という悩みの背景には、この3つのメカニズムが隠れていることが多いのです。

①内臓の位置がずれて消化・代謝機能が低下する

骨盤や背骨が歪むと、その中に収まっている内臓の位置もずれてしまいます。たとえば、猫背の姿勢が続くと胃が圧迫されて消化不良を起こしやすくなります。また、骨盤が傾くと腸の働きが鈍くなり、便秘やむくみの原因になることもあるのです。

内臓が本来の位置からずれると、消化や代謝の機能が十分に働かず、食べたものをエネルギーに変える力が弱まります。その結果、同じ食事をしていても太りやすく、痩せにくい体になってしまうのです。

②血流・リンパの流れが滞り老廃物が溜まる

骨格が歪むと、血管やリンパ管が圧迫されて血流やリンパの流れが滞ります。血液は全身に酸素や栄養を運び、リンパ液は老廃物を回収する大切な役割を担っていますが、この流れが悪くなると冷えやむくみ、セルライトの蓄積につながります。

実際に、姿勢不良によって末梢の血流が約20〜30%低下するという研究もあります。血流が悪いと細胞の代謝も落ちるため、脂肪が燃えにくい体になってしまうのです。

③正しい筋肉が使えず消費カロリーが減る

骨格が歪んでいると、体を支えるために本来使うべき大きな筋肉(お尻の大臀筋、お腹の腹筋、背中の背筋など)が使えず、小さな筋肉だけで体を動かすことになります。大きな筋肉は多くのエネルギーを消費しますが、小さな筋肉ではエネルギー消費量が少ないため、基礎代謝が下がってしまいます。

たとえば、骨盤が後ろに傾いている(後傾)とお尻の筋肉が使えず、太ももの前側ばかりに負担がかかります。その結果、下半身太りや前ももの張りといった悩みにつながるのです。

あなたは大丈夫?代謝が落ちる骨格歪みチェックリスト

以下の3つ以上に当てはまる人は、骨格の歪みで代謝が落ちている可能性があります。ご自身の体をチェックしてみてください。

  • 座るとつい脚を組んでしまう → 骨盤の左右のバランスが崩れているサインです
  • 靴の減り方が左右で違う → 重心が偏り、骨盤や股関節が歪んでいる可能性があります
  • お腹だけぽっこり出ている → 骨盤が前傾または後傾して、内臓が前に押し出されているかもしれません
  • 肩の高さが左右で違う → 背骨が歪み、上半身のバランスが崩れています
  • 便秘がち・むくみやすい → 骨盤の歪みで腸や血管が圧迫されている可能性があります
  • 冷え性で手足が冷たい → 骨格の歪みで血流が悪くなっているサインです
  • 運動しても下半身が痩せない → 骨盤の歪みで下半身の筋肉が正しく使えていないかもしれません

これらの項目は、骨格の歪みが日常生活の中でどのように現れているかを示しています。当てはまる数が多いほど、骨格を整えることで代謝アップが期待できます。

①骨盤を立てる「座り方リセット」

まずは正しい座り方を身につけましょう。椅子に座るときは、お尻の下にある坐骨(座ると当たる骨)を立てるように意識します。腰を反らしすぎず、背筋を自然に伸ばして座ることで、骨盤が正しい位置に収まります。

この座り方を続けると、内臓の位置が整い、腹筋や背筋が自然に使えるようになります。デスクワークの方は、1時間に1回はこの座り方を意識してリセットしてみてください。

②背骨を整える「寝たままストレッチ」

仰向けに寝て、両膝を胸に抱えるようにゆっくり引き寄せます。そのまま左右にゆらゆらと体を揺らしてみましょう。背骨が優しくほぐれ、柔軟性が戻ってきます。

このストレッチは寝る前やお風呂上がりに行うのがおすすめです。背骨の柔軟性が高まると血流が改善し、代謝アップにつながります。

③股関節を緩める「四つん這いエクササイズ」

四つん這いの姿勢になり、骨盤を前後にゆっくり動かします。次に、お尻を左右に振るように動かしてみましょう。股関節周りの筋肉がほぐれ、可動域が広がります。

股関節の動きが良くなると、下半身の大きな筋肉が使えるようになり、下半身の代謝がアップします。1日1回、朝起きたときや夜寝る前に行ってみてください。

注意点: どのセルフケアも、無理をせず心地よい範囲で行ってください。痛みがある場合は無理をせず、専門家に相談することをおすすめします。
